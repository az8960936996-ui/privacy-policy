# Privacy Policy – Kisan Seva App

**Last Updated:** 19 May 2026  
**App Name:** Kisan Seva – PM Kisan Guide  
**Package:** com.azdevelopers.kisansevaapp
---

## Data Collection

This app does **not** collect, transmit, or store any personal data on any server.

## Data Stored on Device Only

If you use the "My Details" feature, the following information is saved **only on your device**:
- Aadhaar Number
- Mobile Number  
- PM Kisan Registration Number

This data is encrypted using Android's secure storage system and is never sent anywhere.

## Third-Party Services

This app loads pages from **pmkisan.gov.in** (official Government of India website) inside a WebView. We do not control or collect data from that website.

## Data Deletion

You can delete all stored data anytime by using the **"Clear All Data"** button inside the app.

## No Account Required

This app requires no login, registration, or account creation.

## Camera Access

Camera is used only for the Document Scanner feature to scan and convert documents to PDF. No images are stored on any server.
